# PDFs

PDFs are not committed: some of the documents used during development are published books that can't be redistributed.

Put any PDFs you want the assistant to read in this folder. `pipeline.py` loads every `data/*.pdf`, and the index rebuilds automatically when the set of PDFs changes.

The development runs used seven football PDFs, including the IFAB Laws of the Game A–Z, an open-access *Applied Sciences* (MDPI) paper, and a football-for-development practical manual.
